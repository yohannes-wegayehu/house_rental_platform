Owner Dashboard Statistics Fix Test

Test Purpose

This test verifies that the owner dashboard statistics are maintained correctly after page refresh.

The fix includes:

  • Statistics persistence in localStorage
  • Loading states during data fetch
  • Cached stats fallback (5-minute expiry)
